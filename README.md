# 비즈업클래스 유료 수강생·챌린지 관리 서비스

`docs/비즈업클래스_유료수강생_챌린지관리_PRD_v1.0.md`를 구현한 웹 서비스입니다.

- 백엔드: Node.js 22.13+ (Express 5) · 내장 SQLite(`node:sqlite`) · 비공개 로컬 파일 저장소
- 프런트엔드: 빌드가 필요 없는 바닐라 JS SPA (`public/`). 수강생 화면은 모바일, 운영자 화면은 데스크톱 기준

## 실행

```bash
npm install
npm run init-admin -- --email admin@example.com --name 관리자 --password '8자이상비밀번호'
npm start                 # http://localhost:3000  (PORT 환경변수로 변경)
                          # 포트가 이미 사용 중이면 3001, 3002… 순서로 빈 포트를 찾아 시작하고 실제 주소를 출력합니다.
```

데모 데이터: 빈 DB에서 `npm run seed`를 실행하면 아래 계정이 생성됩니다.
- 관리자 `admin@bizup.local` / `admin1234!`, 강사 `teacher@bizup.local` / `teacher1234!`
- 수강생 이름 `김민수` / 전화번호 `01011112222`

테스트: `npm test` (PRD 20장 검수 시나리오 기반 API 통합 테스트)

## 화면
| 사용자 | 경로 |
|---|---|
| 수강생 로그인 | `/#/login` (이름 + 전화번호) |
| 강사·관리자 로그인 | `/#/staff-login` (이메일 + 비밀번호) |
| 계정 설정 링크 | `/#/setup/<token>` (관리자가 발급, 24시간·1회용) |

## 구현 요약 (PRD 대응)
- **고유번호**: 강의 `CRS-`, 강사 `INS-`, 학생 `STU-`. 학생은 정규화한 전화번호당 1명(`UNIQUE`)
- **명단 업로드**: xlsx/csv(UTF-8·CP949) → 열 매핑 → 미리보기(DB 미생성) → 행 수정·제외 → 확정(재검사, 백그라운드 처리·결과 재조회)
- **챌린지·과제**: 초안/공개, 한국 시간 기준 기간(종료일 다음 날 00:00 KST 마감), 종료 후 허용/마감
- **동결**: 첫 체크나 첫 제출 시 `locked_at`을 기록하며, 이후 할 일과 제출 필수 설정은 바꿀 수 없음(관리자 포함). 과제 복사로 새 초안 생성
- **자동 완료**: 서버가 계산(모든 할 일 체크 AND (제출 선택 OR 현재 제출물 1개 이상)), 기한 후 완료 구분 보존
- **제출물**: 버전 관리, 파일 확장자·매직바이트·크기 검증, 권한 검사 후 다운로드(영구 공개 URL 없음)
- **피드백**: 학생별·과제별 작성, 버전 기반 읽음 표시, 수정·삭제 이력, 피드백 당시 제출 버전 참조
- **보안**: scrypt 해시, 서버 세션(취소 가능, 역할별 만료), CSRF 토큰, 로그인 시도 제한, 범위 밖 객체 404, 감사 이력

## 운영 설정 (환경변수)
| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 포트 |
| `DATA_DIR` | `./data` | DB·업로드 파일 위치 (백업 대상) |
| `COOKIE_SECURE` | 0 | HTTPS 운영 시 `1` |
| `TRUST_PROXY` | 0 | 리버스 프록시 뒤에서 `1` |
| `STUDENT_SESSION_MAX_H` / `_IDLE_H` | 168 / 24 | 학생 세션 |
| `STAFF_SESSION_MAX_H` / `_IDLE_H` | 12 / 2 | 운영자 세션 |
| `MAX_ATTACHMENT_MB` / `MAX_ROSTER_MB` / `MAX_ROSTER_ROWS` | 20 / 10 / 5000 | 파일 한도 |
| `LOGIN_MAX_FAILURES` | 10 | 15분당 로그인 실패 허용 횟수 |

백업은 서버를 멈춘 뒤 `DATA_DIR` 전체(`app.db*`와 `objects/`)를 함께 복사하세요.

## 알려진 제약
- 단일 프로세스·SQLite 구조입니다. 다중 서버로 확장하려면 PostgreSQL과 객체 저장소로 옮겨야 합니다(스키마는 PRD 15장을 따름).
- 이메일 발송 연동이 없습니다. 강사 설정 링크는 관리자가 복사해서 전달합니다.
- 학생 비밀번호 해시는 대량 등록 속도를 위해 운영자보다 낮은 scrypt 비용(N=2^15)을 씁니다. 전화번호에서 파생된 값이라 원래 엔트로피가 낮습니다(PRD 5.3).
